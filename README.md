# Deutsch Zahlen-Trainer

Hör- und Lesequiz für deutsche Zahlen (0–999.999), für den DaF-Unterricht.

**App öffnen:** https://jaybee2026.github.io/Deutsch-Zahlentrainer/

## Für Lernende

- Einmal mit Internet öffnen, danach läuft die App auch ohne Netz.
- Auf den Home-Bildschirm legen:
  - iPhone/iPad (Safari): Teilen-Symbol → „Zum Home-Bildschirm"
  - Android (Chrome): Menü (drei Punkte) → „App installieren"
- Modus „Hören" braucht eine deutsche Sprachstimme auf dem Gerät.
  Modus „Lesen" funktioniert immer.
